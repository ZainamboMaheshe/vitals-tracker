# Vital Signs Tracker

# About This Project
I created a simple Python program that lets you enter a person's vital signs, including blood pressure, heart rate, and temperature.

The program checks if any of the readings are too high or too low and saves the information in a CSV file.

## What It Does
- Records blood pressure, heart rate, and temperature
- Flags readings that are too high or too low based on example ranges
- Saves the information in a CSV file

## What I Used
- Python
- CSV
- If and else statements
- Variables and loops

## Why I Made This
I'm currently learning Python as a Computer Science student. Since I also work as a Certified Nursing Assistant (CNA), I wanted to create something that connects my healthcare experience with what I'm learning in programming.

## How to Use It
1. Run `main.py`.
2. Enter the vital signs.
3. The program checks the readings.
4. The information is saved in `vitals.csv`.

**Note:** This is just a practice project, not a medical tool. Only use fake patient information.
